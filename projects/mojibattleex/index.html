01 / ABOUT

読める。
殴れる。

メインキャラクターと補助キャラクターでチームを組み、同じPCでわちゃわちゃ対戦。自動通常攻撃、固有スキル、必殺技、パッシブが文字ごとに用意されています。

漢字、記号、単位まで。意味と見た目をそのまま能力にした文字バトルです。

画面いっぱいに飛び出す巨大な文字、画面分割で同時進行する乱戦、残り時間で加速する終盤戦。ネタっぽい見た目のまま、ビルドや相性もしっかり遊べる設計を目指しています。

02 / PLAY

静かな文字は、
いません。

通常対戦、トレーニング、そして全員を盛った超究極スーパーカオス。能力の組み合わせを試せるキャラクターエディタも用意しています。

MODE 01

超究極スーパーカオス

操作キャラ、追従メイン、補助キャラが一斉に出撃。画面の情報量まで必殺技です。

MODE 02

必殺技

文字の意味を、そのままド派手な一撃へ。カットインも画面シェイクも遠慮なし。

MODE 03

ローカル2〜4人対戦

キーボードまたはJoy-Conで同じPCに集合。最後まで生き残るか、残りHP率で勝負です。

MODE 04

つくる・試す・増やす

10枠のカスタムキャラ、トレーニング、外部JAR MOD。遊び方だけでなく中身も拡張できます。

03 / EXPANSION MOD

まだ増えます。

ゲーム本体の公開APIだけを使って作った、独立コンテンツMOD。キャラクター、能力、翻訳、画像をJARひとつで追加します。

CONTENT

育つ「木」、金運を貯める「金」、拡散攻撃の「茶」、累算する「Σ」。さらに支援役として「長」「dx」「眉」「㌠」も参戦します。

拡張MODのリポジトリ↗
ネタバレ：メイン4体の戦い方
「木」は木→林→森→森羅万象へ成長。「金」は金運を会心へ変換。「茶」は拡散通常攻撃を高頻度で維持。「Σ」は累算をためて必殺技へ収束させます。
ネタバレ：補助4体の役割
「長」は回復と速度支援、「dx」は全体デバフと単発防御、「眉」は戦闘の長さを多段攻撃へ変換、「㌠」は決闘と人数差で集団戦を動かします。

05 / UNDER THE HOOD

ふざけた見た目、
まじめな中身。

ゲームルールと描画を分離し、データ・翻訳・能力実装を名前空間付きリソースで接続。標準コンテンツさえ外部MODと同じ流れで読み込む構成です。

Java 21libGDX 1.14.2LWJGL3GradleJSON / I18nTyped Registry
01

固定60Hzのバトル更新

入力をコマンドへ変換し、描画フレームとは切り離して戦闘を更新。人数や画面分割が増えてもルールを追いやすくしています。

02

データ駆動の文字キャラ

キャラクター、能力、フィールド効果、翻訳をJSONとRegistryで接続。見た目と能力を組み替えるカスタム保存にも対応しています。

03

本体とコンテンツを分離

公開API、ゲーム本体、標準コンテンツ、MODローダー、デスクトップ起動層を別モジュール化。外部JARを検証して依存順にロードします。

04

日本語もリソースとして管理

ゲーム内は ja_jp の翻訳キーを検証して読み込み。この紹介ページも同じ考え方で、表示文を翻訳辞書から適用しています。
