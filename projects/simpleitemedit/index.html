MINECRAFT PAPER PLUGIN

Simple
ItemEdit

OP権限がなくても、自分のアイテムを好きな見た目に変えたい。性能を盛るのではなく、名前・色・装飾などの「見た目」に絞ったプレイヤー向け編集ツールです。

Modrinthで入手 ↗GitHub ↗
01 / EDIT MENU

見た目だけを、好きな形へ。

編集項目を選ぶとプレビュー表示が切り替わります。これは操作感を伝える紹介表示で、実際にアイテムを編集するシミュレーターではありません。

名前を変更したアイテム見た目のプレビュー

装備スロット

頭・胸・脚・足・Body・手・オフハンドから装備位置を選択。

チート性能なし

攻撃力、耐久値、エンチャントレベル、個数などの性能変更は対象外。

カスタムモデル

設定ファイルからMODやリソースパックのモデルも登録できます。

02 / BEFORE & AFTER

性能はそのまま、印象を変える。

比較画像はまだないため、同じ比率のプレースホルダーにしています。実画像が届いたら差し替えるだけで並べて比較できます。

BEFORE

元のアイテム画像

AFTER

名前・色・光沢などを編集した画像

03 / HOW TO

コマンドひとつで開く。

Paperサーバーへ導入し、編集したいアイテムを持って /simpleEdit を実行。OP権限は不要です。

PaperMinecraft 1.21.6–1.21.11 / 26.1.x–26.2Kotlin / Java
